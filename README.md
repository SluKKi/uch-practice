# Конференции.РФ

Информационная система для бронирования помещений для проведения Всероссийских конференций.

## Стек технологий

- **Клиент**: React 18, Vite, TypeScript, React Router 6, Lucide React
- **Сервер**: Node.js, Express, TypeScript, Prisma ORM, JWT, bcryptjs
- **База данных**: PostgreSQL

- `/server` — бэкенд REST API на Express + TypeScript + Prisma ORM

## Установка и запуск

### 1. Настройка базы данных

Убедитесь, что служба PostgreSQL запущена на `localhost:5432` и создана база данных `conferences_db`:

```sql
CREATE DATABASE conferences_db;
```

Файл окружения `server/.env`:

```env
PORT=5000
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/conferences_db?schema=public"
JWT_SECRET="supersecretkey_conf_rf_2027"
```

### 2. Установка зависимостей

```bash
npm run install:all
```

Или по отдельности:

```bash
cd server
npm install
npm run prisma:push
npm run seed

cd ../client
npm install
```

### 3. Запуск в режиме разработки

В первом терминале (бэкенд):

```bash
cd server
npm run dev
```

Во втором терминале (фронтенд):

```bash
cd client
npm run dev
```

Клиент доступен по адресу: `http://localhost:5173`
Сервер доступен по адресу: `http://localhost:5000`

## Реализованный функционал

1. **Регистрация (`/register`)**:
   - Строгая валидация на клиенте и сервере:
     - Логин: только латиница и цифры, не менее 6 символов
     - Пароль: минимум 8 символов
     - ФИО: только кириллица и пробелы
     - Телефон: строго в формате `8(XXX)XXX-XX-XX`
     - Email: корректный адрес электронной почты

2. **Авторизация (`/login`)**:
   - Проверка логина и хэшированного пароля
   - Выдача JWT токена
   - Информативные сообщения об ошибках
   - Перенаправление в зависимости от роли (`ADMIN` -> `/admin`, `USER` -> `/dashboard`)

3. **Личный кабинет пользователя (`/dashboard`)**:
   - Список всех поданных заявок пользователя
   - Статусы заявок с цветовой дифференциацией
   - Форма добавления отзыва о мероприятии для заявок со статусом «Завершено»

4. **Формирование заявки (`/create-request`)**:
   - Выбор типа помещения («Аудитория», «Коворкинг», «Кинозал» или произвольное название)
   - Выбор даты и времени проведения
   - Выбор способа оплаты: очно при посещении или по системе СБП

5. **Панель администратора (`/admin`)**:
   - Доступ только для пользователей с ролью `ADMIN`
   - Таблица всех заявок в системе с данными заявителей
   - Изменение статуса: «Новая» -> «Мероприятие назначено» -> «Завершено»
   - Фильтрация по статусам и быстрый поиск по заявителю или помещению
